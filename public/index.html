Is your app leaking API keys?

Anyone can open your site, press Inspect, and copy the OpenAI, Gemini, Stripe or Supabase key inside it. Paste any website address, on your own domain or any host, and see what they see.

Reads only the public files your site already sends to every visitor. Keys are shown masked. Nothing is stored.

What it checks

Any site, any host

Your own domain or Lovable, Bolt, Vercel, Netlify, Railway. React, Vite, Next.js or plain JS: we read the HTML, every bundle, lazy chunks and public source maps.

30+ key types

OpenAI, Anthropic, Gemini, OpenRouter, Groq, Stripe, Supabase, GitHub, AWS, Slack, Resend, ElevenLabs and more.

No false alarms

Stripe pk_, Supabase anon and Firebase web keys are public by design. We say so instead of scaring you.

Two hard truths

A key in the browser can't be hidden

Obfuscation and encryption fail: the key shows in the Network tab the moment it's sent. The only fix is that the real key never reaches the browser.

A leaked key is burned

If it was ever public, assume it's copied. Create a new key once, then keep it off the browser.

Scan before you publish

npx leaklock scan dist/          # your build folder
npx leaklock scan myapp.com      # a live site
npx leaklock scan dist/ --fail-on=secret   # fail CI if a secret ships

Zero dependencies. MIT licensed. Your keys never leave your machine.
