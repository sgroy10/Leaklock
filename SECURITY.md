# Security policy

If you find a vulnerability in LeakLock itself (for example, a way the web checker could reveal a full key or reach a private network), please report it privately through GitHub's **Report a vulnerability** button on the Security tab of this repository, rather than in a public issue. You'll get a reply within a few days.

LeakLock is designed so that:
- keys are masked before they leave the scanner,
- the web checker stores nothing and refuses private and internal addresses,
- scans only read files a normal browser would load.

Please only scan sites you own or have permission to test.
